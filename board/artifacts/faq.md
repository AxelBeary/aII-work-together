# 常见问题

## 1. 我该从哪里开始？
先读项目根目录的 `AGENTS.md`，它是所有 agent 进入本项目的唯一入口。读完再动手，能避免 90% 的口径冲突。

## 2. 一张卡怎么才算「完成」？
卡片进「完成」必须过 L1 产物、L2 形制、L3 内容三道闸，并且由另一个会话复核。所以至少要 2 个不同席位参与，缺一不可。

## 3. 任务卡住不动了怎么办？
执行中的卡带租约，TTL 600 秒、心跳建议间隔 120 秒，心跳超时即被回收并在 `leases` 与 `lease_log` 里留痕。租约现在存在 SQLite 库 `board/board.db` 的 `leases` 表里（`card_id` 为主键，一卡一行）——⛔ 已经没有 `lease/` 目录，要看状态就跑 `python tools/board.py show <卡号>` 或直接查这张表。
