> 甄别没做，后续全是错账。若某目标**确实定位不到可靠来源**，写 `未能定位` 并说明你试过哪些检索词——这比编一个像的答案有价值。

### 1.1 定位到之后，每个目标给这些维度

| 维度 | 说明 |
|---|---|
| 正名＋归属 | 公司／团队／个人，官网与仓库链接（带访问日期） |
| 它到底是什么 | 一句话人话（是产品？框架？平台？论文？服务？） |
| 与我们的关系 | 是否在做「多 agent 协作／看板／编排」这件事？**是正面竞品、可借鉴件，还是无关** |
| 形态与部署 | Web／CLI／桌面／SaaS；自托管是否可行 |
| agent 接入 | 支持哪些引擎；有无通用适配层 |
| 协作模型 | 谁派活／谁认领／有无租约心跳／有无人类审批位 |
| 完成判据 | 完成和验收怎么定（自报？看产物？跑闸门？） |
| 许可 | 许可证全文标识（闭源要写明闭源） |
| 活跃度 | star／版本／最近提交（**必须亲眼看到**，写访问日期） |
| **可用性判定** | `可用`／`部分可用`／`不可用`／`未证` |
| 最有价值点／最致命缺点 | 各一两句人话 |
