## 1 任务与范围

回答：**这个看板要跑在本机，那本机已经有什么能当它的「执行臂／底座」？又有哪些硬约束必须一开始就守住？**

必须覆盖：

1. **执行臂盘点**（本机 CLI agent 引擎）：读 `%USERPROFILE%\.agents\skills\agent-delegation\references\targets.md`，把每个引擎的**无头调用最小式／判成败口径／沙箱档位／能力边界**抽成一张表；标注哪些**必须现场复算**才能用。
2. **方法学可复用件**：读同一技能的 `references/orchestration-lessons.md` 与技能主文件，抽出**能直接变成看板功能/规则**的条目（例：进度契约→卡的心跳字段；写入凭证→完成判据；席位制→看板角色列）。**逐条给「技能原文位置→可落成的看板机制」的映射**，⛔ 不许泛泛说「可以借鉴」。
3. **本机现成工装/信道**：`<repos>\` 下哪些项目里有可直接复用的东西（如 `sentinel-ops` 的插件宿主与治理范式、`agent-delegation` 项目本体、`renforge-mcp` 的 MCP 形态、`waypost`）；RTOC 信道能力与硬上限（读本机记忆/文档，⛔ 不读密钥内容）。
4. **硬约束清单**：从全局纪律 `~/.config/opencode/AGENTS.md`、本项目 `AGENTS.md`、本机记忆（persona／human 画像）里抽出**会被看板实现撞上**的约束（例：人机验证禁令、桌面可见物禁令、密钥禁令、单轮拍板 3-4 条、用户非程序员→交付必须免看代码可验收、机翻感＝缺陷式审美标准）。
