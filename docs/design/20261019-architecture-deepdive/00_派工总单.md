## 二、共同纪律（三席同守）

1. **不写代码**（D-002）。交件里可以出现伪代码／JSON 示例／状态转移表，⛔ 不出现可运行的源文件。

3. **落盘用文件写入工具直写**：⛔ 用 PowerShell 写任何件。
4. **必须回应三条红线**（`AGENTS.md` §4）：状态即证据／人的拍板位不可越／认领即租约。**设计若与红线冲突，写「冲突」并停，⛔ 不得自行放宽红线**。
