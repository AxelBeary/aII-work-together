# 托盘程序（右下角常驻）

> 原生 C# + WinForms，**不是 Electron**。编译后 **14 KB**，常驻内存约 20 MB。

## 怎么用

双击 `tray\tray.cmd`（首次会自动编译，之后直接启动）。

右下角出现一个蓝色「板」图标，双击打开看板。

**右键菜单**：

| 菜单项 | 干什么 |
|---|---|
| 打开看板 | 起后端（没起的话）+ 打开浏览器 |
| 跑一轮 | 后台跑 3 张卡，完成后弹提示告诉你「有几张等你拍板」 |
| 看看状态 | 弹一句人话：共几张、完成几张 |
| 开机自动启动 | 写注册表 Run 键（**点了才生效，默认不开**） |
| 退出 | 关掉托盘，同时关掉它拉起的后端 |

## 为什么这样设计

| 选择 | 理由 |
|---|---|
| C# + WinForms | Windows 自带组件，**不需要装任何东西**；单 exe；启动 <1 秒 |
| 不做 Electron | Electron 一个空壳就 100 MB+、常驻 200 MB；我们只放一个图标 |
| 壳不管业务 | 所有看板逻辑仍在 Python 后端，壳只负责「起停 + 打开」 |
| 运行时画图标 | 不额外带 .ico 文件，少一个二进制资产 |

## 技术细节

- 单实例：用命名 Mutex，重复双击不会开第二个
- 后端端口默认 8777，可用 `boardtray.exe --port=9000` 改
- 端口冲突时托盘会有提示，不会静默失败
- 日志：`board\tray.log`

## 自检（不弹托盘）

```cmd
tray\boardtray.exe --selftest
```

它会：检查后端是否活着 → 不在就拉起来 → 再探一次 → 打印 `SELFTEST PASS/FAIL` → 退出。
**全程不创建托盘、不弹任何窗口**，用来验证「壳能不能把后端拉起来」。

## 重新编译

改完 `tray\BoardTray.cs` 后，删掉 `tray\boardtray.exe` 再双击 `tray.cmd`，或直接：

```cmd
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe ^
  /codepage:65001 /out:tray\boardtray.exe ^
  /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:System.Net.Http.dll ^
  tray\BoardTray.cs
```

> `/codepage:65001` 必须有——源码里有中文，不加会乱码。
