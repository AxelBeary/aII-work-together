# 怎么用（真人版·五分钟）

> 你现在只需要记住 **3 条命令**。其余都是它自己干的。

---

## 第一次：建一个令牌（只做一次）

打开 PowerShell，粘贴：

```powershell
Set-Content -Path "$HOME\.board-human.tok" -Value "换成一个只有你知道的长串" -NoNewline
```

> 这个文件是「你的印章」。**没有它，任何人都不能替你拍板**（包括 agent）。
> ⚠️ 不要把它给 agent，也不要把内容贴进任何对话。

---

## 每天：三步

### 第一步：建卡（说清要什么）

```powershell
board add --title "给 README 加常见问题" --goal "回答三个新手问题，每条不超过两句"
```

**就这一条**。不用选引擎、不用选模型——项目默认值会说。

想让它必须经过你点头：

```powershell
board add --title "..." --goal "..." --human-gate before_done
```

---

### 第二步：让它自己干

```powershell
orch run --max 5
```

它会：找活 → 认领 → 调 agent → 自动验收 → 换个会话复核 → 不过就返工 → 需要你拍板的停下等你。

**你不用盯着**。跑完会打印一行汇总。

---

### 第三步：看有没有等你拍板的

```powershell
board inbox
```

你会看到：

```
📥 待你拍板：1 张

[1] C1019-cd02  写一份 FAQ
  目标    回答三个新手问题
  执行    opencode/deepseek
  产出    board/artifacts/faq.md(621B)
  门禁    ✓ L1-L3 全过
  复核    pass by rev-dfec
  凭据    存在，621 字节，10 行，md5 前 8=3857333E
  花费    $0.0006

  建议    批准 —— 门禁全过 + 异会话复核通过且有凭据
  批准    board human C1019-cd02 --decision approve --who owner
  驳回    board human C1019-cd02 --decision reject --who owner --note "要改什么"
```

**复制最后两行里的任意一条**就是你的全部工作。

驳回时写的话会传给下一轮 agent，它会**针对性改**，不会重做一遍。

## 四个你可能想用的命令

```powershell
board            # 现在什么情况（面板）
board ls         # 所有卡 + 状态
board open       # 生成看板网页
board all        # 所有项目的情况（团队视角）
```

---

## 多个项目怎么办

**在哪个项目目录下跑 `board`，就是操作哪个项目。** 不用切换、不用配置。

第一次在某个项目用：

```powershell
cd D:\某个项目
board add --title "第一张卡" --goal "试试"
```

它会自动建看板、自动登记。

看全部项目：

```powershell
board all
```

## 出问题了

| 现象 | 敲这个 |
|---|---|
| 不知道现在什么情况 | `board` |
| 觉得卡住了 | `board doctor`（体检，`--fix` 自动清） |
| 怀疑有人绕过命令行改数据 | `board audit` |
| 想看花了多少钱 | `board cost` |
| 想看某张卡的全部经过 | `board show <卡号> --events` |
| 想删掉一张卡 | `board rm <卡号> --yes` |

**一条命令跑完所有自检**（改过代码才需要）：

```powershell
python tools/check.py
```

## 它替你守的四条线

| 你会担心 | 它怎么管 |
|---|---|
| agent 说做完其实没做 | 必须过三道机器闸 + 换个会话复核，缺一不进「完成」 |
| 两个 agent 抢同一张卡 | 数据库主键锁死，只有一个抢得到 |
| agent 自己验自己 | 复核席和执行席是同一人，直接拒 |
| agent 替你拍板 | 没你的令牌，它连这条命令都没有 |

## 更省事的方式：双击托盘，用鼠标

命令行那套照旧能用，但日常其实可以完全不敲命令。

### 开起来

双击 `tray\tray.cmd`。右下角出现一个蓝色「板」图标。

- **双击图标** → 打开网页看板
- **右键** → 打开看板 / 跑一轮 / 看看状态 / 开机自动启动 / 退出

### 网页上看板怎么用

| 你想做的事 | 怎么做 |
|---|---|
| 看所有项目 | 顶部下拉框选「全部项目」 |
| 只看某个项目 | 下拉框选那个项目 |
| 建一张卡 | 右上角「+ 新建任务」，填标题和目标（其余留空就行） |
| 看一张卡干到哪了 | 点那张卡，里面有完整经过 |
| 批准 / 驳回 | 卡停在「拍板中」时，卡片底部有按钮；**驳回必须写理由**（会传给下一轮） |
| 让 agent 干活 | 右上角「跑一轮」 |
| 看花了多少钱 | 卡片上直接显示，每张卡独立计 |

### 两个小提醒

- 「跑一轮」只能对**具体某个项目**用。选「全部项目」时这个按钮会变灰——因为一次只能驱动一个项目的活。
- 网页只在本机能打开（`127.0.0.1`），别人访问不到；关掉托盘就全停了。
